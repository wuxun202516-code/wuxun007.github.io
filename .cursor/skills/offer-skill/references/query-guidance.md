# 自然语言查询指引

## 意图映射

| 用户表达 | 使用能力 | 参数映射 |
|---|---|---|
| 最近有什么校招、今天更新了什么 | `recent` | 默认 `limit=20` |
| 今天截止、马上截止 | `deadline` | `within_days=1` |
| 三天内截止 | `deadline` | `within_days=3` |
| 一周内、七天内截止 | `deadline` | `within_days=7` |
| 某公司校招 | `search` | `companyName`；名称不确定时可用 `keywords` |
| 某类岗位 | `search` | 明确岗位名用 `positionName`，职能类别用 `functionName` |
| 某行业 | `search` | `industry` |
| 某城市 | `search` | `city` |
| 某届毕业生 | `search` | `graduationYear`，必须是整数 |
| 本科、硕士等学历 | `search` | `educationLevel` |
| 国企、民企等性质 | `search` | `companyNature` |
| 秋招、春招等批次 | `search` | `recruitmentBatch` |

## 追问原则

- “最近有什么校招”直接查询 `recent`，不要强迫用户先补充条件。
- “帮我找适合我的校招”至少需要了解毕业届别；城市、学历和职位方向会显著影响结果时，再用一个简短问题补齐。
- 公司、岗位或行业表达存在明显歧义时再追问，不要为了追求字段完整而连续询问。
- 用户提出 2、5、10 天等不受支持的截止窗口时，明确只能选择 1、3、7 天，请用户选择；不要静默取整。

## 结果表达

推荐结构：

```text
查询条件：2027届｜北京｜产品岗位
本页返回 8 条。

1. 校招名称｜企业全称
   批次／届别：秋招｜2027届
   岗位：产品岗、运营岗
   城市：北京、上海
   截止时间：2026-10-31
   网申地址：...
   来源／更新时间：官网｜2026-08-31 10:00:00
```

- 只能用 `items.length` 表述“本页返回数量”；接口没有返回总量时，不要声称是全部结果。
- 当 `hasMore=true` 时写“还有更多结果，可以继续查看”，不能推断剩余数量。
- 比较多个机会时，只比较接口有值的字段，并把比较依据写出来。
- 链接缺失时可以提供公告链接；两者都缺失时写“暂未提供链接”，不要自行搜索或拼接地址。
